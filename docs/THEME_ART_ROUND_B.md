# 主题与诗画：B 轮独立配置实验

本记录保留 B 轮原始结果。后续统一纸纹、阅读用途、默认路由与快照机制的最终结果见 [统一验收记录](THEME_ART_FINAL_REVIEW.md)，最终 B 样张在 `round-b-final/`。

2026-10-28。实验分支 `feat/theme-art-validation`，基于 Claude 的 `8194e65`。未修改既有海报、视频或 App 的行为。

## 实验入口

```bash
node scripts/theme-art-study.mjs
# 自定义输入和输出目录
node scripts/theme-art-study.mjs examples/theme-art-study.json out/theme-art-validation/round-b
```

脚本使用现有本地服务、Chrome、字体、Worker 和排字模块。入口是独立实验页面，不是 `generate.mjs` 的新命令。

输入字段：

| 字段 | 意义 |
| --- | --- |
| themes | 界面主题列表，本轮鸦青、月白、苍筤 |
| appearances | 浅深列表；本轮都显式指定 |
| artworks | `shanshui` / `flowers` / `none`，分别调用 shanshui@5、nonflowers@2 或关闭景物 |
| artPalette | 独立绘画墨色来源，本轮固定鸦青；只取其 ink，不代表移植该主题的矿物设色笔法 |
| flower | 自然、梅、荷、菊、兰；本轮自然，不宣称具体物种 |
| seed、title、author、poem | 固定种子、诗题、作者、摘句 |

本轮固定《春日》「胜日寻芳泗水滨，无边光景一时新」，避免用明显指向某一种花的诗句测试“自然”花卉。三套主题 × 浅深 × 山水/花卉/素纸共 18 张。不同绘画类型的几何必然不同，同一绘画类型跨主题保持种子与参数一致。

主题控制纸色、文字、作者强调色与印色；绘画的 ink 来自独立 artPalette，花色沿用引擎原色，不用 accent 染花。绘画纸底使用主题 paper，避免矩形底色接缝。浅深模式可以改变绘画 ink；不是保证两个模式每个像素不变。

## 输出与检查

目录：`out/theme-art-validation/round-b/`。

- 18 张 1080×1440 原图。
- `contact-light.png` / `contact-dark.png`：每行一个主题，每列依次山水、花卉、素纸，标签放在画外。
- `manifest.json`：原始输入。
- `checks.json`：解析后的颜色、完整绘画请求、诗句框、排字结果、图像校验值与浏览器版本。

验证结果：

1. 新增的 3 项规则测试通过：换主题不改绘画墨色/花卉/种子；换绘画配置不改界面配色；不支持的值明确失败。
2. 18 张都成功渲染，未出现脚本或资源错误、字体缺失、文字超出诗句框或诗句删减。
3. 18 张完整排字结果相同，诗句位置、字号、题款、印的尺寸均未因主题或绘画类型改变。
4. 鸦青浅、深的花卉分别重新加载页面，使用全新 Worker 生成，绘画 Canvas 像素逐字节一致。
5. 已人工查看两张接触表，并放大苍筤浅花卉、月白深山水。

这里只验证上述样本，不等于穷举种子、花卉种类、阅读字号或跨浏览器一致性。

## 审图结论

- **配置分离成立**：同一幅画可以自然接入三种纸色，作者名和印色随主题变化；花的原色仍然保留。浅色三套差异克制，深色纸底差异更容易看出。
- **花卉适合继续做阅读背景实验**：本样本左侧花枝、右侧诗句，疏密关系清楚；深色花瓣能看见。但放大后枝茎接合处有方块状硬边，浅色花瓣较淡，不能据此宣布花卉画法已通过美术验收。
- **Web 山水需要单独打磨**：本样本远山/远岸/近树的层次分离明显，坡岸有硬边，深色山水主体偏暗。这些来自当前 Web 画法，不能靠界面主题规则直接解决。
- **纸纹仍不统一**：山水与花卉保留各自引擎的纸纹，素纸使用固定细噪纹；两种引擎纸纹比素纸明显，尤其原图上较重。后续若做阅读背景，应统一或减轻纸纹，而不是增加一层毛玻璃。
- **素纸语义正确**：只保留字、题款与印，不再用“纯壁纸（无字有画）”代指无景物阅读底。

## 下一轮边界

本轮是显式配置实验，尚未提供自动主题推荐、按诗句自动选择花卉、seasonal 解析、已保存作品加载或全文阅读模式。也没有完成青绿/金碧/没骨笔法迁移。C 轮应首先覆盖《山居秋暝》《江雪》《梅花》《小池》，检查实际诗意和阅读区，再决定默认路由；避免在本轮样本上过拟合。
