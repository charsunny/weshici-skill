旧毫束盖印路径仍保留作像素实验。生产山石使用完整笔体上的栅格接触与单块湿染扩散；两条路径不可混称为同一实现。新检查 `tests/zxart-terrain-ink.browser.mjs` 直接验证生产路径。

`babc517` 的栅格墨感已获阶段性认可，尚未通过终稿验收。`de74eca` 的石岸、苔点与去灰团获得认可，但整幅过薄、鱼骨状松冠和不明显的清泉被否定。本轮恢复贴形湿染与浓皴，改为不对称针簇、鳞皴树干和独立点叶/夹叶杂树，并把清泉移入山间石坎。深色反相效果已由用户明确选择保留。对照时仍应观察山面笔簇的重复感、近岸转折与树屋的自然关系，不能因渲染模型更新就宣称接近原画。

## 以下为 3f1abf5 历史记录，已被用户否定，不代表当前效果

### 同一岩面的栅格笔墨试验

本轮只回答：在岩面与行笔路线不变时，替换墨的生成方式能否改善笔墨？不以通过测试或减少图元数作为审美验收。

### 复现

在仓库根目录运行：

```bash
node scripts/landscape-ink-study.mjs out/theme-art-validation/ink-study
node tests/zxart-raster-ink.browser.mjs
node scripts/theme-art-review.mjs
```

`ink-study/index.html` 包含 A/B/C/D、现有整层滤镜、D 的勾皴染点累积过程，以及原画与候选同像素尺寸裁切。`scene.json` 保存 D 的完整路径、压力、纸色和各层参数；`checks.json` 保存实现版本、源码 SHA-256、浏览器版本、PNG SHA-256 和渲染耗时。复现以保存的源码版本为准，不承诺不同浏览器、平台逐像素一致。

参考图从本地 `out/theme-art-validation/landscape-flow-reference/cha-shibiao-detail.jpg` 复制；缺少时仍可运行笔墨对照，但不展示原画。来源为亚洲艺术博物馆的[查士标作品局部](https://education.asianart.org/wp-content/uploads/sites/6/2019/09/B69D41_Landscape_Detail.jpg)，B69D41，1686。图像只用于比较，不参与生成。笔法次序参考 [Brushstrokes 第 20 页](https://education.asianart.org/wp-content/uploads/sites/6/2019/09/Brushstrokes.pdf#page=20)。

### 控制变量与实测

固定 `bank-proof`，逻辑画幅 240 × 110，输出 960 × 440；观察原生成器调用，不更改其随机消耗。原岩面包含 655 个图元。

| 版本 | 变化 | 观察 |
| --- | --- | --- |
| A | 原矢量叠染，不使用纸面滤镜 | 硬边、平涂和重复扇形笔路明显 |
| B | 保留全部图元，按勾皴染点分层使用现有 drawWashed | 边缘变软，未产生自然飞白 |
| C | 每笔改完整笔体，84 个淡染图元合成 4 块染面，使用 drawWashed | 总图元降为 49，但宽笔与染块更显平涂 |
| D | 相同行笔路线，逐毫沉积墨量，染面做扩散 | 断墨、墨束厚薄、叠笔与湿边有变化；原有卷曲笔路和扇形染面仍然突出 |

C 的透明度由图元面积估算，并不与 A 精确等墨量；D 也使用新的沉积模型，因此本页比较的是渲染方式，不是经过色度校准的等浓度实验。图层重排到勾、皴、染、点的次序。

现有 `tooth=.95` 在当前纸面上仍保留 0.765–0.983 的 alpha，均值 0.873，没有接近透明的采样。它能减薄墨色，但单靠此参数不能产生明显的方向性飞白。现有 `multiply` 只控制层间混合，同层相邻同色形状仍由 `drawShapes` 合批，不能代替逐笔积墨。

### D 的实现与边界

`resources/vendor/zxart/zxart-ink.js` 提供 `ZXArtInk.draw`，Worker 遇到 `layer.ink` 时使用它。当前版本标识 `bristle-study-1`，具体实现以源码哈希区分。只有试验场景产生这种图层，完整山水生成器尚未改接。

- 沿路径按弧长盖印，笔压改变接触宽度；不等宽、不等墨量的毫束共享局部接触变化，各毫继续独立耗墨。
- 干笔靠接触与耗墨留下沿笔路的空隙，不将整面山石铺上颗粒。湿笔增加连接笔毫的墨体，避免横点成为空心轮廓。
- 同一纸面高度场用于所有墨层，影响局部接触与相邻像素的扩散。它是程序噪声近似，不是真实纸纤维模型，也没有与旧宣纸贴图逐纤维对齐。
- 先在栅格上累积光学密度，再转成 alpha；交叉笔迹自然加深。湿染使用对称邻域扩散，边缘加深是经验近似，没有模拟水分蒸发、颜料输运或真实毛细作用。
- 当前只验证浅纸黑墨；主题色、深纸浅墨以及整幅峰岸的遮挡和光向尚未验证。扩散最多 160 步，不能把 `bleed` 解释为物理半径或宣纸吸水率。

### 检查与视觉结论

真实 Canvas 检查通过：同输入所有像素一致；换种子改变落墨；干笔在湿笔覆盖范围内露纸；提按改变覆盖宽度；同层多笔累积墨量；湿染扩散到原多边形之外；实际 Worker 的新分支产生像素。固定 D 连续渲染的 PNG 哈希一致，桌面和手机宽度的对照页无横向溢出。

本轮没有达到接近原画的水平。D 比矢量平涂多了断墨和软边，但仍像三组重复的折角笔簇，大片石面缺少结构，淡染也是固定扇形。不能把这一版直接宣布为新的完整山水默认画法。下一轮要把这些问题连同光向、转折、皴笔生长和峰岸结构一起处理，而不是继续给当前三组笔簇增加纸纹。
