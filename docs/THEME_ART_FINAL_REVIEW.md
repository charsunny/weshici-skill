## 实现结果

1. **主题与绘画配置分开**。新作默认绘画墨色随主题，题材来自诗意；显式绘画/墨色选择优先。花色不使用 accent 染色，绘画纸色与页面一致。
2. **四首诗的路由**。山居秋暝走山居林泉；江雪沿用匹配器的冬雪寒林并包含舟、钓翁与雪；梅花进入 nonflowers@2 的梅；小池走荷塘夏景，也可显式选独立荷花。
3. **用途分开**。题诗仍用竖排诗句框；阅读完整横排正文，景物独立在底部生成，正文区不铺景物。超出固定阅读区报错，不偷偷删句。
4. **纸感收敛**。实验入口关闭引擎背景纸纹，统一使用极淡的固定纸层；深色山水适当加强笔迹。原入口不传新参数，保持原处理。
5. **快照固定**。保存实际颜色、主题、日期、构图请求、种子、尺寸和用途。重放绕过现有默认值；资源或浏览器版本不匹配会拒绝静默重画。
6. **规则进入 Skill**。SKILL.md 增加入口，详细行为、命令、边界和 App 映射放在 `references/THEME-ART.md`，不让普通出图任务误用实验参数。

## 人工审图与建议

已查看最终 B 轮浅深接触表、C 轮四张接触表、全部动态组接触表；放大过花卉、山水与阅读样本。

- 支持采用「默认随主题、允许独立绘画、题材由诗意决定」。同一花卉进入不同纸色不突兀，不需要把花染成绿色或把所有诗都变成山水。
- 全文阅读应优先保证纸面与文字，底部小景是可选陪衬。相比题诗画屏，阅读背景故意降低画面的占比；不将其作为完整山水构图的审美标准。
- 素纸是一项完整选择，对长篇、密集阅读及减少视觉干扰有意义。
- 当前 Web 绘画能力不足以直接承诺原生五画风效果。主题/用途规则可以迁移；笔法仍需独立对齐。

## 明确保留的问题

1. Web shanshui@5 某些坡岸、树干和远近景衔接仍有程序化硬边；山居的主山线条偏重。实验未重写 Claude 已有景物系统。
2. 深色梅枝较暗，花簇/枝茎局部接合仍显生硬。已保留花色，不以全局染色掩盖问题。
3. 既有深色视频山水细节偏淡，部分镜头字与画仍可继续调整比例。本轮只抽查，不顺带改写视频模板；同样未完成原计划中独立的 poet-footprint 升级。
4. 自动题材仅有限词组与现有匹配器，不是完整诗意理解；不支持的具体花种不假装已经能画。
5. 阅读目前固定 3:4 和字号，不自动分页。App 迁移前必须补动态字体、多设备、辅助功能与原生渲染审图。

这些问题随样张一起交由用户统一验收，不能把“自动检查通过”写成“国画美术已经通过”。
