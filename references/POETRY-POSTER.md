# 诗词海报 · poster

用于大字诗句、社交分享封面、同一主题的诗词组图。配色用 App 的七套主题色（第四稿）× 浅深。原则同 App：**主角是诗和画，配色不抢戏；底近中性；颜色只在小处；朱只在印。** 背景与壁纸继续用 `image` / `wallpaper`；Wish 同款要求读 IOS-HUAPING.md。

## 视觉与内容

- 一张海报只有一件主角：摘选的 1—2 行主句，单色墨，思源宋体 Bold。其余文字用 Regular，层级只有三层：主句／副题与出处／页脚。
- 页面是纸色平铺，加极淡的纸纹；没有渐变天空、深色压条或大面积色块。浓一点的颜色只放进画里。
- 画是确定性 Canvas 山水：远山、主峰、前叠一层低岭、对岸小山，水面上有自两侧伸出的沙渚、横向波纹与倒影，近岸一角承载母题。地形由种子生成，同组每张都不同；横排版式的主峰升到文字块下方留一口气的地方，画是第二主角。山顶浓、山脚入雾，近景中景设色浓一级、远山淡；深色模式的雾比纸略亮（月下薄雾），不是更暗的纸。画在页脚之上晕入纸色。
- 构图让位给字：先排字，再按文字所占区域压低山峰、限制树高。`vertical` 竖排主句在右上，主峰在左；`horizontal` / `hero` 主句在上，画在下部；`cover` 主题大字，画可略满。
- 印每张一方：App 原生竖印「微詩」，按该套配色的 `seal` 色着色，横排跟在作者后，竖排落在作者下。月的半径为画宽 5%，浅色的月是留白的纸，四周淡染（烘云托月）。落日是朱砂：浅色印色向该套赭石（`secondary`）借两成，中心实、边缘化开，半径 3.5%；浅深都用浅色那份印色，不淡成粉色，也不比印抢眼。
- 落款写真实诗题、作者；作者名用该套 `accent`。品牌／二维码／两行日期整体垂直居中，右侧是短题与编号。诗句二维码使用现有 `weshici://poem/lookup`，封面二维码打开微诗官网。
- 主题组图共用日期、主题与编号，可做一张封面＋逐诗海报；数量以任务和诗单为准，不固定七张。`subtitle` 是短副题，引用原诗时核对原文，编辑文案不能冒充诗句。
- 本模板非 AI 生图，非 ShanShui@5 输出。只实现 3:4 静态 PNG；不声称已经适配抖音 9:16 控件、自动生成视频或验证传播效果。

## 命令

在 skill 根目录运行，需要 Node.js、Chrome 与 `npm install` 安装的依赖。

```bash
# 单张海报；--poem 用标点或换行明确分为一至两行。不传 --palette 时随节气
node scripts/generate.mjs poster --title "山居秋暝" --author "王维" --poem "明月松间照，清泉石上流" --palette qingdai --appearance dark --layout vertical --date 2026-10-27 --out out/poster-shanju

# 完整组图；此示例为 2026-10-27 的芦荻主题存档（霜降，随节气为月白），不代表运行当天
node scripts/generate.mjs poster --manifest examples/poster-ludi.json --out out/poster-ludi

# 配色样张：同一首诗 × 七套 × 浅深，共 14 张
node scripts/generate.mjs poster --manifest examples/poster-palettes.json --out out/poster-palettes
```

`--out` 是目录。输出顺序编号的 PNG，组图额外生成 `contact-sheet.png`（中性灰底），并保存 `manifest.json`。不传日期时用北京时间当天；给定日期与种子、相同字体和浏览器环境可复现。

## Manifest

```json
{
  "theme": "山间明月",
  "date": "2026-10-27",
  "cards": [
    {
      "layout": "cover",
      "title": "山间明月",
      "lines": ["山间明月"],
      "subtitle": "与诗相伴的一轮月色",
      "palette": "seasonal",
      "appearance": "light",
      "motifs": ["sun", "pine"]
    },
    {
      "title": "山居秋暝",
      "author": "王维",
      "poem": "明月松间照，清泉石上流。",
      "lines": ["明月松间照", "清泉石上流"],
      "layout": "vertical",
      "palette": "qingdai",
      "appearance": "dark",
      "motifs": ["moon", "pine"],
      "caption": "松风明月"
    }
  ]
}
```

| 字段 | 规则 |
| --- | --- |
| `theme`、`date` | 全组主题（最多 16 字）、YYYY-MM-DD 日期 |
| `title`、`author` | 诗题最多 32 字、作者最多 12 字；封面可省略作者 |
| `lines` | 1—2 行，每行最多 8 字；封面 1 行、最多 4 字。更长主题可放在 `title`、`subtitle` 中，封面主标题另选短题 |
| `poem` | 可附完整原文；渲染前会检查主句是否出自原文，组图建议保留以便核验 |
| `layout` | `horizontal`（默认）、`vertical`、`hero`（每行最多 5 字）、`cover` |
| `palette` | `seasonal`（默认）或七套之一：`yaqing` 鸦青、`moon-white` 月白、`xiang-leaf` 缃叶、`canglang` 苍筤、`ousi` 藕丝、`qingdai` 青黛、`rouge` 胭脂 |
| `appearance` | `light` 或 `dark`。缺省时：母题含 `moon` 取 `dark`，否则 `light`；弃用别名自带浅深 |
| `motifs` | `sun`、`moon`、`reeds`、`maple`、`cottage`、`fortress`、`pine`、`boat`、`heron`；日月二选一，空数组可只保留山水。省略时为日（深色为月）＋松树＋舟楫 |
| `subtitle`、`caption` | 可选副题最多 28 字（支持换行）、页脚短题最多 8 字 |
| `seed` | 可选固定种子；省略时从日期、主题、序号与诗题确定 |

### 配色

色值在 `resources/core/app-palettes.json`，逐值取自 zixiao-kit `origin/master` 的 `Sources/ZixiaoDesign/Resources/identities/<id>.json`（提交 SHA 记在文件 `source.commit`）。海报用到的槽：`paper` 页面，`ink` 主句与品牌，`muted` 副题、诗题与页脚小字，`accent` 作者名，`seal` 印与落日（取浅色那份），`surface` 二维码底。画色（`painting`）是海报自己的，按每套的来历推出：

| 配色 | 来历 | 画的设色 |
| --- | --- | --- |
| 鸦青 `yaqing` | 黑白主色 | 纯水墨，远淡近浓 |
| 月白 `moon-white` | 花青 × 赭石 | 浅绛：花青远山与山头，赭石淡染山脚近岸 |
| 缃叶 `xiang-leaf` | 缃 × 绀青 | 绀青画山，缃只染坡脚与秋树 |
| 苍筤 `canglang` | 石绿 × 赭石 | 青绿：石青远山，石绿山头，赭石坡脚 |
| 藕丝 `ousi` | 茄紫 × 柳绿 | 茄紫远山，柳绿近景 |
| 青黛 `qingdai` | 青黛 × 泥金 | 浅色青黛染山；深色是磁青纸泥金，泥金勾线 |
| 胭脂 `rouge` | 胭脂 × 石绿 | 石绿画山，胭脂只点枫叶 |

远近层次是画色与纸色按距离混合（远淡近浓），不是每层另配一色。深色模式纸是深色，远山更接近纸色，近景更亮并由勾线托出。

**随节气**（`seasonal`）按卡片日期所在节气取季，与 `ZXPaletteCatalog.palette(for:)` 一致：

| 季 | 节气 | 配色 |
| --- | --- | --- |
| 春 | 立春—谷雨 | 苍筤 |
| 夏 | 立夏—芒种 | 胭脂 |
| 长夏 | 夏至—处暑 | 缃叶 |
| 秋 | 白露—霜降 | 月白 |
| 冬 | 立冬—大寒 | 青黛 |

**弃用别名**（保留一版，新 manifest 不要再用）：`qinglv` → 苍筤浅色，`yueye` → 青黛深色，`nuanjin` → 缃叶浅色。显式写的 `appearance` 优先于别名自带的浅深。

## Wish 今日主题组图

用户要求「今日推荐」时，读取公开 `https://www.weshici.com/api/v1/home/recommendations`，确认 `data.issue_date` 与 `data.theme`（`title`、`picks[].poem`），记录实际期次。每首从 `title`、`author.name`、`paragraphs` 取诗题、作者和原文。不要把本地样例、过期缓存或模型另选的诗称为今日推荐；接口不可用时明确缺失，不自动套用芦荻样例。

按实际诗单编写 manifest；封面突出主题，各诗选一组适合放大的摘句，并选择母题与浅深（月夜用深色）。同组缺省随节气同一套配色，需要时再逐张指定。接口中的赏析是辅助信息，摘句以诗的原文核验；存疑的组诗序号和朝代标注不要直接照搬。

## 出图检查

CLI 检查脚本／资源错误和文字越界。导出后查看并排图，必要时看单张：

- 360px 宽缩略图里主句清楚；长题缩小但不越界、不挤压印；
- 同一组各张地形不同；画面母题符合诗意；
- 没有米黄或金的大面积，页面底是纸色；朱只出现在印和朱砂落日，落日不读成粉色；深色山脚没有比纸更暗的横带；
- 深色海报的二维码是浅底深模块，能扫；日期清晰、页脚整体居中；
- 文字不越界，山峰和树没有压进文字。

发现问题修改对应卡片的排版、摘句、母题或浅深，再导出检查。

## 移植到 App

给 iOS 分享海报用。比例按画布宽 W 计（本模板 W = 1080，3:4 画布高 H = 4/3 W）；画面高度方向的位置按 H 计。

**配色映射**：直接用 App 当前身份的槽，海报不另调色。

| 海报元素 | 槽 |
| --- | --- |
| 页面底 | `paper`（加极淡纸纹，不渐变） |
| 主句、品牌 | `ink` |
| 副题、诗题、日期第二行、短题与编号 | `muted` |
| 作者名 | `accent` |
| 印 | `seal`（竖印「微詩」着色） |
| 落日 | 浅色 `seal` 向浅色 `secondary` 混 22%；中心不透明度约 0.82（深色 0.86），外缘 12% 化开 |
| 二维码 | 模块用浅色 `ink`，底用浅色 `surface`；深色模式也一样 |
| 画 | 该套 `painting`（`far` / `top` / `body` / `line` / `point`），与 `paper` 按远近混合 |

**版式**（W 的百分比）：

| 项 | 规则 |
| --- | --- |
| 页边 | 左右 8.1%；文字块顶 13.9% |
| 主句字号 | 横排 min(10.7%, 77.8% ÷ 最长行字数)；hero min(14.6%, 79.6% ÷ 字数)；竖排 min(9.3%, 70.4% ÷ 字数)；封面 min(21.9%, 71.5% ÷ 字数) |
| 主句排布 | 横排行高 1.38、字距 0.04 em；竖排字距 0.14 em、两列间距 0.34 em，右边距 8.9%，列从右向左 |
| 副题 | 3.0%，行高 1.7，主句下空 3.1% |
| 出处 | 诗题＋作者 3.0%（长题缩到不小于 2.6%，仍放不下就换行），副题下空 2.4% |
| 印 | 宽 3.3%、高 6.9%，横排在作者后空 2.0%，竖排在作者下 |
| 页脚 | 底边距 5.4%，高 11.1%；品牌竖排 2.8% Bold；二维码 11.1%（含 0.74% 内边距）；日期两行 2.4%，行高 1.62；元素间距 2.0%；短题与编号右对齐 2.4% |
| 日月 | 月半径 5%，落日半径 3.5%（上限 7%） |
| 画面 | 水平线：横排 68–73% H，hero 69–74% H，封面 66–72% H，竖排 73–78% H；横排、hero、封面的主峰最高到文字块底边下 3.5% H（主峰高度取「水平线到该处」的 86%–100%，不超过 32% H）；山脚与水平线上淡入的雾：浅色是纸色，深色是纸向墨混 10%；画在 85%–90% H 之间晕入纸色；页脚顶边约 87.6% H，品牌与日期都落在纸上，二维码自带底块 |

**印与页脚规则**：每张只有一方印，页脚的「微诗」是品牌字，不加框、不用印色。品牌／二维码／两行日期作为一组垂直居中；页脚不压在画的实处，画在页脚前淡尽。字号不低于：出处 2.6% W，页脚与日期 2.4% W。
