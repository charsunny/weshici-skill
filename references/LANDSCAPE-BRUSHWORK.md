# 山水笔法与种子生成 · landscape-v3

这是 weshici-skill 的程序笔法验证，不是 App 迁移，也不以自动测试代替美术验收。

## 资料与阅读范围

主资料为亚洲艺术博物馆教师工作坊教材 [Brushstrokes: Styles and Techniques of Chinese Painting](https://education.asianart.org/wp-content/uploads/sites/6/2019/09/Brushstrokes.pdf)，并非算法论文。以下页码为 PDF 页序（含封面），不是正文印刷页码。已核对相关文字及图版：

- 第 19–20 页，查士标作品及局部：看构图中的行进路线、断续勾线和淡染如何共同组织山石。
- 第 40–41 页，点法、皴法图版：点叶有方向和组合；披麻与斧劈的形态、行笔方式不同，皴笔服务于山石结构。
- 第 43–45 页，基本笔法、执笔及装墨示范：提按、倾斜、含水量和装墨方式影响同一笔的形状与墨色。

山势另对照故宫 [范宽《谿山行旅图》](https://theme.npm.edu.tw/selection/Article.aspx?sNo=04000959) 的主峰、两侧山峰和山石皴纹关系，以及 [郭熙《早春图》展览说明](https://theme.npm.edu.tw/exh108/npmxkmfa/ch/page-3.html) 的三远与墨色空间。

## 实现规则（我们的程序近似）

| 层次 | 本版实现 | 随机变化的边界 |
| --- | --- | --- |
| 山势 | 主峰、左右峰肩、前层岩块相接；保持题诗留白 | 种子改变峰位、宽高、遮挡、左右方向；不用满屏噪声决定构图 |
| 岩面 | 每块岩石定义同一曲面，供轮廓、阴面、皴笔采样 | 岩面有共同的转折方向，避免纹理独立漂浮 |
| 披麻近似 | 沿结构布置长短不齐的干笔，明面疏、转折密 | 变长短、起点和笔压，不打乱坡向 |
| 斧劈近似 | 侧锋宽起、逐渐收尖，集中在转面和裂隙 | 一张画保留主导皴法，不无差别混合所有笔型 |
| 笔触 | 局部法线方向的提按轮廓、侧面墨色差、分毫露纸 | 墨量、湿度、宽度独立；露纸用透明空隙，不用白笔覆盖下层 |
| 点叶 | 松树主枝弯转分叉，枝梢以聚散针叶和墨点成冠；阔叶成组点写 | 组间留空、尺度不齐；避免整齐椭圆贴片 |
| 主题 | 继承主题纸色、墨色、字体；山体小笔触局部点色 | 长而窄的洗染色带不参与山尖点色，避免整片阴面变成色块 |

主导皴法由诗境决定：实验模板识别望岳、岱宗、泰山、华山、峭壁、绝壁、千仞等题材为斧劈，其余默认披麻；结果保存为请求内部的 `params.scene.cun`。这是简单关键词规则，不是完整的诗意理解。种子不再切换皴法；山体、叶簇、坡石各有带用途前缀的独立随机序列。旧处理仍使用原来的随机序列。相同版本、输入和 seed 重放一致；不同 seed 的变化受到上述结构约束。输出 `brushwork` 记录本次主导皴法，可核对保存的皴法选择。

新模式对完整字符串做顺序敏感的哈希和混合，再初始化局部随机流；不沿用旧初始化的编码字符求和，以减少相近编号的相关性和重排字符串碰撞。建筑沿坡岸落位时另避开已有树干区域，避免重排后出现房屋搭在树干上的错觉。

当前仅近似披麻、斧劈及相关点叶；没有实现完整云头皴、米点皴，也没有真实水墨扩散、纸纤维吸水或湿上加湿的破墨模拟。深色主题是现代 UI 的墨色映射，不是传统黑纸绘画复原。仍应检查重复峰形、笔簇机械感和前景衔接，不能因引用教材就宣称达到传统画作水准。

## 复现与审图


第一步输出笔触及同种子双皴法证明页；第二步输出多种子、浅深、不同诗意与全文阅读矩阵。主验收页将新图与 483a8b9 保存的上一稿 PNG 对照，历史各轮仍保留。按单笔、岩面、整幅的顺序审图，同时看缩小后的效果。旧配方遇到源码版本变化仍拒绝静默重放。

配置使用 `elementTreatment: "landscape-v3"`；其他入口和默认 `refined-v1` 不变。此版本允许景物边界变化，因此天气锚点必须来自新几何，不能继续套用上一版的锚点。

## 原画对照后的继续修订

上一稿（42c5972）的主要问题是等距细丝式枯笔、相似峰肩、大面积平滑明面，以及树屋与近岸墨量不足。本次仍修订显式 landscape-v3 候选，不另增用户配置：

- 枯笔改为不等长、不等宽的断续落墨；按距离补足采样，使只有两端点的直笔也能有中段提按。露纸仍为透明缺口。
- 峰肩使用不同转折轮廓；每个岩面的倾斜不同，长短皴笔沿共同裂隙成组错落。
- 近岸增加与原岸面相接的洗染、转面、折线裂隙及短皴；前景树屋与坡岸使用明确的墨色层次。修正新模式镜像坡岸的两套坐标别名不一致。
- 松叶收拢位置、长度与组间距离有所变化，但尚未重做树干分枝拓扑，树冠重复感仍在。

当前样张用 `landscape-mass-after`，重放用 `landscape-mass-replay`，笔触证明用 `landscape-mass-brush`；上一轮 `landscape-after` 保留作为固定种子对照。验收页顶部提供前后全图及局部。两轮源码不同，必须各自使用所保存版本重放，不能混用旧配方和新源码。

本轮视觉判断：前景承托与墨色层次更清楚，但皴笔、峰形、松冠仍有程序感，未达到原画自然笔墨。不要将本轮修订表述为传统山水画复原完成。

## 积墨、山石搭接与树法重做

继续对照 PDF 第 20 页的横向断带转为纵斜侧笔，以及第 40–45 页的点叶、皴法和装墨示范：

- 先修复真实渲染路径：Canvas 原先将相邻同色图元合并填色，使多遍淡染只剩一遍。新皴染携带 `overprint`，在拟合、设色和导出中保留，渲染时逐遍填色；旧图元继续原有合批语义。浏览器像素测试验证两遍、三遍半透明墨分别累积到约 75%、87.5% alpha。
- 山体采用十三块高低错落的短岩面搭接。横向峰肩转为向下裂隙，皴笔及不规则淡染共用曲面；染色限定在岩面内，避免宽笔晕出轮廓。
- 枯笔有较淡的连续笔势和错落搭接的笔毫，各毫宽度、落墨长度和墨量不同，避免两条等重边线形成空心管，也避免整笔横向断开成块。湿笔分段改变墨量，起收和转折仍由整笔压力控制。
- 松树根点固定，主干折转、主枝上挑、细枝再次分叉；枝端以疏密不齐的针叶与点墨成冠。岸坡由倾斜主体和少量脚石组成，同一场景不同岸坡使用不同但可重放的随机流，避免重复盖章。
- 岩石层使用已有纸面滤镜做轻微边缘扰动，并保留完整像素分辨率；没有实现真实毛细扩散或湿墨混色。

当前证据目录为 `landscape-structure-after`、`landscape-structure-replay`、`landscape-structure-brush`；79b9812 的 `landscape-mass-after` 保留为同种子对照。证明页增加整棵松树与完整坡岸，避免只凭单笔证明判断整幅。

视觉界限：墨色厚度、叠嶂和树枝关系已有实质变化，但岩面组合仍重复，局部洗染平滑，皴笔仍带程序特征。不能将这些变化或回归通过表述为“已经接近原画水平”。


## 按原画局部再校正：阴阳面与折带

本轮直接采用 VPS Claude 转来的审图意见，参考博物馆发布的[查士标原画局部](https://education.asianart.org/wp-content/uploads/sites/6/2019/09/B69D41_Landscape_Detail.jpg)（作品 B69D41，1686，[资料页](https://education.asianart.org/resources/brushpainting-nature-in-art-school-program-selected-resources/)）。原图只作对照，不参与生成。

- 撤回中间试验 `landscape-flow-grain` 的整层墨粒，worker 回到 483a8b9 的实现；没有引入山面各向同性噪点。枯笔缺口沿笔势分布在笔触内部，细笔不再强拆成亚像素的六条细丝；负向侧锋同步反转浓墨边。
- 山体从十三块改成九块肩面，次峰增加宽肩与偏峰。明面取消整面墨底，阴面及转折聚集皴染。各岩面按淡湿断勾、顺势皴、薄染、浓淡横点顺序生成；前后岩面的遮挡仍由纸色遮罩处理。
- 岩面底边由统一平底改成起伏收脚，缩小过界的洗染范围。固定样张左侧硬截边消失；`fitted` 本身只拟合，不裁剪，问题来自局部岩面的闭合边与受限洗染几何。
- 近岸替换旧长平板遮罩，以错落肩线、斜收脚和前后遮挡构成台阶；小石减少折笔数量。笔路先横行、到角处按下侧锋再向下；干擦紧随同一转角，淡染从缝向外展开，最后补浓淡横点。溪流使用同一套石法，并用断续岸线串联。
- 主峰缩窄，客峰位置抬高，减少轮廓完全重合。曾尝试单独拉长水路，但造成上游石块悬空，已撤回；贯通近远的 S 形路径尚未完成，须连同坡岸和山谷构图一起重做。

本轮输出 `landscape-flow-after` / `landscape-flow-replay` / `landscape-flow-brush`。验收页增加原画与候选的局部并排，使用相同图像像素尺寸、同缩放对齐，并保留同种子的前后对照；不声称按原作实物尺寸校准。原图需另存为 `out/theme-art-validation/landscape-flow-reference/cha-shibiao-detail.jpg` 才展示原画区，其来源说明同目录保存。

剩余差距：披麻笔簇仍偏卷曲，重复的岩面搭接与折带节奏可辨认，岸石干擦缺少原画的厚薄变化。主客峰已有分离，但溪流仍只在近岸，整体龙脉尚不充分。继续保留试验版本，不切换默认，不迁移 App；这些变化并不代表已达到原画水平。
