# 风格母版 03 · 诗人行迹（`poet-footprint`）

适用：20–60s 诗人行迹短片（如苏轼黄州、惠州、儋州）。舆图在纸上，行迹线是全片唯一的颜色，每站以题跋式文字落款。

## 1. 内容来自配方，只写事实

配方（例 `resources/recipes/sushi-footprint.json`）列出站点、诗与纪年事件：

- 站点：地名、经纬度、在任年号与公元起止（如「元丰三年—七年 · 1080—1084」）、诗题、写作年份、诗句与出处说明（诗库没有的诗写明据通行本）。
- 纪年事件：年份与四字以内的事件（如「乌台诗案」「前后赤壁」）。
- 不写年龄（虚岁、周岁有歧义）、不写因果附会或拼凑的地名典故，不加注释段落。

## 2. 舆图

- 主题纸色上的淡墨舆图：站点按经纬度投影（经度乘 cos 纬度，不东西拉伸）；海岸、海岛、江河为平滑淡墨线，山以古舆图式小山形标出（`resources/core/footprint.js` 的 `GEOGRAPHY`，按大致经纬度描的示意，配方写明）。陆地一层淡墨晕，边缘渐隐，不留方框；海面留白。
- 行迹线用配色的浅色印色，是全片唯一的颜色；只依次连接各站，不表示实际行程（配方写明）。到站前 1.2s 生长到下一站。
- 城市名 40px；当前站点墨色，其余淡色，当前城市有一圈淡墨涟漪作余韵。

## 3. 站点题跋

- 三层，不加阴影卡片：诗句（66px，逐字墨洇）、出处（署名、诗题、写作年份，30px）、一行语境（地名、在任年号与公元起止，30px）。
- 换站时上一站像墨入水一样化开，下一站再出字。

## 4. 纪年刻度

- 刻度在真实年份的位置；标注分在刻度线上下两排，每个标注放进偏移最小的一排，永不重叠、不越出刻度尺（`rulerLayout`，有单测）。被挤开的标注用短引线连回刻度。
- 年份与事件不小于 28px；当前站的事件墨色，其余淡色。
- 全部文字在 1080×1920 的安全区内（右 140px、底 380px 不放字）。
