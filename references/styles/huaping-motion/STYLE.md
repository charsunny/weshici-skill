# 风格母版 01 · 动态画屏（`huaping-motion`）

适用：每日一诗、节气日签、金句分享视频。成片是「会动的画屏」：和静态 `image` 同一引擎、同一套排字，加上 App 的入场和落定后的余韵。Wish 原生行为以 [iOS 画屏实现基准](../../IOS-HUAPING.md) 为准，Web 与原生的差异见该文第 8 节。

## 1. 画面

- **画**：ShanShui@5，`poetryScene(诗句, 诗题).paintingProcedural(seed, { purpose: 'inscription-v1' })` 得到完整场景配方；配方只记 `generator` 与 `seed`，用途、构图、母题由引擎按诗决定。引擎所选场景遮住诗的主角时，配方可写 `scene` / `composition` / `motifs`，并在 `procedural.note` 写明理由（例：江雪改用渔隐场景，让孤舟钓者可见）。`renderZXArt` 返回 `ok: false` 时直接报错，不用简化山水顶替。
- **9:16 构图**：画在 1440 / 1560 / 1680 高的画布上生成（取墨量最大者，配方可用 `artHeight` 固定），不缩放、底边对齐放进 1080×1920；画的最后一笔若停在平台底栏之上，就裁掉下面的空纸往下移。诗句框经空白纸面上提到约 11% 高度：诗在上、画在下。画上方的纸面用画自己的空白纸条续铺，没有接缝。不拉伸画。
- **配色**：App 七套主题色 × 浅深（`resources/core/app-palettes.json`）。`palette` 缺省 `seasonal`，按配方 `term`（或 `date`）的节气取季；月夜题材缺省深色。页面纸色平铺，不用米黄与渐变。默认 landscape-v3 保留引擎墨阶，不做整幅 2.4 倍加墨；深色仍为反相，在线条与淡染的图元层分别提高可读性，纸纹不增亮。显式 original 保留旧加墨处理。
- **朱只在印**：App 竖印「微詩」按配色 `seal` 着色。landscape-v3 保留引擎落日及其遮挡；显式 original 仍换成海报 v2 的朱砂落日（`resources/core/cinnabar-sun.js`），只在引擎原落日露出的范围内画，山前仍遮住它。

## 2. 字与层级

- 诗句框与题款都由 `huaping-layout.js` 的 `huapingPlan` / `mountHuaping` 排出，和静态画屏一致：竖排，右起，题款（诗题、署名）与印在左。
- 只有三层：诗句、题款、印。没有页眉、角印、农历行、注释段落或术语标签。署名用「朝代 · 作者」，朝代未知只写作者，都来自配方。
- 字号：诗句由诗句框决定（约 60px）；题款最小 28px（`minInscription`），放不下时诗题单独成栏。诗句框内残留的发丝线（远水）淡回纸色。
- 安全区：文字不进右侧 140px、底部 380px（抖音控件区），画可以铺进去。

## 3. 时间线

- 入场按 HuapingInkReveal：0.3s 起，每字 0.25s、错开 0.12s、三次 ease-out（模糊 6pt→0、scale 1.06→1、透明度 0→1）；题款 0.18s；最后一字后 0.3s 落印，0.2s、1.15→1，无回弹。金句视频全部最晚 3.0s 落定，长诗压缩错开。
- 时长：`DUR = ceil(入场结束 + clamp(正文字数 × 0.3, 6, 20))`；有朗读时至少容纳整段录音。
- 余韵：背景 1→1.02 线性缓推（文字不动）；天气按诗与画里实有的母题选（`pickWeather`：画里有月不叠月，@5 不加雾层），涟漪只落在空白水面与船边（按像素取样确认），一带淡雾沿远山漂移，「一雁」只画一只。只用墨与纸色。

## 4. 验收

看 9 帧接触表与落定后 0.5s 间隔的三帧：诗在上、画在下，没有大片空纸；朱只在印与落日；落定后画面在缓慢变化但不晃眼；文字不越界、不进安全区。
