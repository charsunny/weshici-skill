# 风格母版 01 · 动态画屏（`huaping-motion`）

适用：每日一诗、节气日签、金句分享视频与全文详情视频。Wish 原生行为以 [iOS 画屏实现基准](../../IOS-HUAPING.md) 为准。现有 `resources/templates/huaping-motion/index.html` 是 Web 模板，尚有文末列出的差异。

## 1. 先选择输出类别

| 类别 | 原生入场与构图 |
|---|---|
| 金句分享 | 首帧成画；0.3s 起笔，诗句、落印及补充文字最晚 3.0s 落定；保持原笺样版式并为页脚缩短诗栏框 |
| 全文详情 | 首帧成画；0.4s 起笔，单元 0.25s、错开默认 0.3s、压缩跨度最多 2.1s，最晚 2.5s 落定；安全框 x=15%、y=8%、宽70%、高72% |
| App 今日页 | 日期/题签/诗句从 0/0.15/0.7s 开始，逐字不受视频预算压缩；尊重减弱动态与 VoiceOver |
| Live Photo | 独立作画段与余韵段，不能沿用分享视频的首帧完整成画规则；需原生照片与 MOV 配对 |

文字落定后保持静止。原生落印为 0.2s、scale 1.15→1、三次 ease-out，无回弹。全文背景线性缓推至 1.02；金句仅在存在天气或余韵时 smooth 推镜，幅度最多 2%。

## 2. 画风、字体与诗句框

- 新画作默认「随诗意」，或明确选择水墨、浅绛、青绿、金碧、没骨；版本字段与纸墨、构图一并保存。旧作缺字段保留原纸墨。UI 主题与作品独立。
- 金碧需要局部山脊/屋脊点金，没骨需要实际去线与晕染；Web 引擎尚未移植这些笔法，不能用滤镜替代后声称原生同款。月白、藕荷等是纸色情绪表，不是五种画风。
- 原生新作继承当前字体，已有配方保留所选字体；按简繁字形覆盖回退。Web 模板使用自己的本地字体，排字前等待 `document.fonts.ready`，不宣称与 App 字体一致。
- 新山水及荷塘使用完整 `shanshui@5` 场景配方，梅、菊、兰等专门花卉用 `nonflowers@2`。保留用途、构图、母题、seed 与返回的诗句框。
- 锁屏题诗保留至少 32% 顶部空白，包括两栏短诗；分享图、组件和详情视频使用各自布局，不能共用壁纸安全区。
- 金句页脚左右各 4% 画宽、底距 5% 画宽，高 `min(30%画宽, 30%画高)`；诗栏不得进入页脚。有落款时左侧另留 23% 画宽给品牌/入口码。补充文字放不下先省解析，再省夹注。
- 全文一屏至多缩到 0.8 倍，仍放不下应报告无法容纳，不能删诗冒充全文。夹注与解析只使用已有资料，不编造来源。

## 3. 天气与阅读停留

天气用真实天空、水面、山脊与舟楫锚点定位，按 @5 母题去重；照片、AI 图、纯纸没有这套程序化天气。文字落定或余韵循环时不重置天气时钟。

两种分享视频：`hold = clamp(正文无标点字数 × 0.3, 6, 20)`，`DUR = ceil(实际入场结束 + hold)`，30fps。署名不计正文字数；朗读版必须容纳完整音频。金句与全文的入场上限不同，不再统一使用 2.8s。

## 4. 使用现有 Web 模板时

模板当前仍是 0.35s 起点、2.15s 诗句预算及 0.22s 回弹落印，补充文字另算入场；它不能直接作为上述原生时间线的验收结果。示例中的 @2 配方也不会仅因文档更新而变成完整 @5 配方。

普通 Web 风格创作可使用现有模板。明确要求 Wish 同款时，先按 [能力差异表](../../IOS-HUAPING.md#8-本仓库-web-能力与验收边界) 修正所用模板或使用原生导出。检查首帧、落定帧、尾帧、长诗溢出、真实字体和阅读时长，并报告实际实现范围。
